# Python Intermedio - Estructuras de Control Repetitivas

Este repositorio ha sido desarrollado para el curso de **Python Intermedio**. Contiene ejemplos prácticos y didácticos orientados a la enseñanza de lógica de programación y estructuras de control dinámicas utilizando la entrada de datos vía teclado (`input()`).

## 📂 Estructura del Proyecto

* **📁 ComandoFor/**: Ejemplos prácticos utilizando el bucle `for` y la función `range()`, como generadores automatizados de tablas de multiplicar con límites dinámicos.
* **📁 ComandoWhile/**: Scripts basados en el bucle `while`, enfocados en la validación de ingreso de datos en tiempo real y acumulación de variables (ej. sistemas de registro de notas).

## 🤝 ¿Cómo contribuir o mejorar este proyecto?

Si eres estudiante de ingeniería o colega instructor y deseas alimentar este repositorio con nuevos ejemplos de estructuras repetitivas, puedes hacerlo de las siguientes maneras:

2. **Vía Fork & Pull Request**:

   * Modifica o añade tus nuevos ejemplos de código en Python.
